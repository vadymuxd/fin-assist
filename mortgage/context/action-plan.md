## Phase 1 — Immediate Actions (April 2026)

The 6-month early-switch window opens in the first days of April 2026. These steps should happen now.

- [ ] **Search aggregators** for current best available rates at ~85% LTV on ~£556,000
  - Recommended tools: MoneySuperMarket, Habito, Trussle, L&C Mortgages, Mojo Mortgages
  - Filter for: 2-year fixed, 5-year fixed — compare both
  - Note: check if paying down slightly to hit 80% LTV bracket meaningfully improves rates
- [ ] **Record the best rates found** (update `market-snapshots/` folder with date-stamped findings)
- [ ] **Decide: broker or direct?**
  - Option A: Contact Oliver (existing broker) for advice and sourcing
  - Option B: Apply direct to lender(s) found via aggregator
  - Option C: Use both — get Oliver's view, then verify against your own aggregator research
- [ ] **Begin the application / reservation process** for the best rate found
  - Most lenders allow you to reserve a rate and switch without penalty if a better one emerges before completion

## Phase 2 — Ongoing Monitoring (April – October 2026)

Once a rate is reserved or applied for, continue to monitor the market.

- [ ] **Weekly: check aggregators** for any rate changes (the scheduled agent task handles this)
- [ ] **React to Bank of England decisions**:
  - Next MPC meeting dates: check https://www.bankofengland.co.uk/monetary-policy/upcoming-mpc-dates
  - If BoE cuts the base rate → reassess current reservation and look for better products
  - If BoE holds or raises → review whether current reserved rate is still competitive
- [ ] **If a materially better rate becomes available** (typically >0.1–0.15% improvement):
  - Assess whether switching is worth the admin effort
  - Check for any reservation/application fees already paid (and whether they're refundable)
  - Update the reservation or start a new application
